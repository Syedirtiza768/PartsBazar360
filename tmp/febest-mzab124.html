Catalog help

  1. Searching auto parts by model:
    • You can write in the field “Model” a part of model name, for example “TOYOTA” and the site will show to you, what models contain this word.
    • If you select the “all” value into the category field the site will show all parts in all categories for selected model.
    • If you select one of category values but does not select any model the site will show only part for selected category for all models.
  2. Searching auto parts by OEM:
    • If a part does not have any OEM but it's a piece of component node you need to use the node number. Those parts are have the “#” sign in begin of OEM.
  3. Searching arm bushes by it's sizes:
    • This site is allow you to search arm bushes by it's sizes. To use this feature you need:
      • Press “Start selection” button or select “rubber parts” into the “category” field.
      • Select the arm bush type.
        (“Type 0” is a floating arm bush etc…)
      • It's better to set the B parameter (the landing size) first. By setting new parameterth the site will reduce available arm bushes list.
